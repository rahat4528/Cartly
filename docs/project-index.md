# Cartly Project Index

Comprehensive index of the 12 applications contained within the Cartly repository:

| # | Folder | Project Display Name | Category | Primary Database | Key Capabilities | Status |
|---|---|---|---|---|---|---|
| 01 | `01-online-bookstore` | Online Bookstore | E-Commerce | `cartly_bookstore_db` | Multi-format catalog, ISBN search, inventory movement audit, recommendations, coupons | Completed |
| 02 | `02-progressive-web-app-store` | Progressive Web App (PWA) Store | Mobile Commerce | `cartly_pwa_store_db` | Offline browsing, background action sync queue, Web App Manifest, push notifications | Completed |
| 03 | `03-job-board-platform` | Job Board Platform | Marketplace | `cartly_job_board_db` | Applicant tracking pipeline, resume uploads, candidate filtering, company portals | Completed |
| 04 | `04-hotel-booking-system` | Hotel Booking System | Hospitality Reservation | `cartly_hotel_booking_db` | Multi-night availability engine, seasonal pricing, temporary reservation holds, invoices | Completed |
| 05 | `05-restaurant-reservation-system` | Restaurant Reservation System | Dining Reservation | `cartly_restaurant_reservation_db` | Table allocation, slot buffer rules, combinable tables, automated waitlist promotions | Completed |
| 06 | `06-movie-ticket-booking` | Movie Ticket Booking | Entertainment Ticketing | `cartly_movie_booking_db` | Interactive seat matrix, real-time temporary seat locks, QR code tickets, scanning gate | Completed |
| 07 | `07-grocery-delivery-app` | Grocery Delivery App | On-Demand Delivery | `cartly_grocery_delivery_db` | Delivery slot capacity, item substitution preferences, recurring scheduled orders | Completed |
| 08 | `08-car-rental-system` | Car Rental System | Fleet Rental | `cartly_car_rental_db` | Date-range availability, tiered duration pricing, security deposits, damage inspection | Completed |
| 09 | `09-real-estate-listing-platform` | Real Estate Listing Platform | Spatial Property Marketplace | `cartly_real_estate_db` | Spatial coordinate search (bounding box/radius), agent listings, price history records | Completed |
| 10 | `10-house-rental-platform` | House Rental Platform | Residential Leasing | `cartly_house_rental_db` | Tenant background applications, private documents, viewing scheduler, lease management | Completed |
| 11 | `11-airbnb-clone` | Airbnb Clone | Short-Stay Accommodation | `cartly_airbnb_db` | Host listing onboarding, dynamic pricing rules, instant booking holds, stay reviews | Completed |
| 12 | `12-flight-booking-system` | Flight Booking System | Demonstration Travel Booking | `cartly_flight_booking_db` | Multi-segment itineraries, fare classes, seat assignments, demo e-ticket issuance | Completed |
